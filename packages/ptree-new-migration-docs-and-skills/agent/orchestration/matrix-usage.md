# Workstream matrix — how to use it

`discoveries/matrices/agent-workstream-matrix.csv` lists **role names** (Source Profile Agent, Media/IPL Contract Agent, etc.) mapped to migration concerns. Use it when a blocker narrative needs a believable “who would have caught this early” — not as a launch script.

Read the matrix for vocabulary and coverage gaps; do not treat each row as a mandatory child agent or a gate ID. Phases and stop rules live in `workflow.md`. Gate CSVs track artifact presence for automation; they do not replace Confluence + profile evidence in client-facing analysis.
